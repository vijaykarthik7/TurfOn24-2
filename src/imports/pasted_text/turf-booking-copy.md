# 10. UI / Interaction Direction

To make the website feel **premium rather than like a standard turf template**, I’d structure the visual experience around the idea of **“game night / stadium energy.”**

### Hero

* Cybernetic grid shader reacts subtly to mouse movement.
* Heading reveals word-by-word.
* CTA has a magnetic hover interaction.
* Small stadium-light glow follows the cursor.
* Scroll indicator continuously pulses.
* Hero content should **not** feel overloaded with cards.

### About

Use a **storytelling split layout** rather than a standard two-column section.

As the user scrolls:

* Image slowly reveals through a masked animation.
* Text enters line-by-line.
* Stats count upward.
* A subtle field-line graphic moves horizontally.

### Features

Avoid six identical cards.

Instead, use an **interactive facility explorer**:

* Large central turf image/visual.
* Six facility labels positioned around it.
* Hovering a facility highlights its corresponding area.
* The selected facility expands with its description.
* Icons animate independently.

This will make the section feel much more custom.

### Gallery

Use an **asymmetrical masonry composition** rather than equal-sized cards.

Interactions:

* Images slightly zoom on hover.
* Cursor changes to “VIEW”.
* Selected image expands into a lightbox.
* Images reveal at different scroll speeds.
* Some images can overlap slightly to create a more editorial sports-photography feel.

### Pricing

Don't use three pricing cards.

Make the **₹700/hour** the visual centerpiece.

For example:

**₹700**
`PER HOUR`

Then place a subtle animated line underneath:

`01 HOUR → ₹700`
`02 HOURS → ₹1,400`
`03 HOURS → ₹2,100`

The numbers can update smoothly rather than showing separate pricing cards.

### Booking

Make the booking experience feel like a **match setup sequence**.

At the top:

`01 VERIFY → 02 DATE → 03 TIME → 04 DURATION → 05 REVIEW → 06 PAY`

The active step can illuminate like a stadium scoreboard.

Each completed step collapses into a compact summary while the next step slides into view.

### Extended Booking

Make this visually different from hourly booking.

Use a large enquiry panel with:

* Date-range visualization
* Animated calendar
* Timeline from start date → end date
* Requirements textarea
* Progress indicator

This makes it feel like a **custom event enquiry**, not another booking form.

### Contact

Use a split layout:

**Left:**
Contact information + large location typography

**Right:**
Contact form

Then place the map underneath as a wide visual section.

### Overall motion language

Use **different motion patterns per section** instead of applying the same fade-up animation everywhere:

| Section          | Main interaction                    |
| ---------------- | ----------------------------------- |
| Hero             | Mouse-reactive shader               |
| About            | Scroll storytelling                 |
| Features         | Interactive facility explorer       |
| Gallery          | Parallax + image zoom               |
| Pricing          | Animated number transition          |
| Booking          | Step-to-step transitions            |
| Extended Booking | Interactive timeline                |
| Contact          | Map reveal                          |
| Footer           | Subtle magnetic/social interactions |

That combination will give the site a much more **premium sports-brand identity** while keeping the background and overall visual language consistent.
